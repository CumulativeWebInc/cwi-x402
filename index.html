How x402 works

1 · Call unpaid
Your agent hits a paid route with no payment attached.
2 · Get a 402
The server answers 402 Payment Required with a signed challenge: scheme, price, USDC asset, payTo address.
3 · Sign & resubmit
The wallet signs (EIP-3009) and the request goes back with an X-PAYMENT header.
4 · Settle & receive
A facilitator verifies and settles on Base; the server returns the data plus a receipt.

FAQ

What is x402?
An open payment protocol (x402-foundation) that makes HTTP 402 "Payment Required" a real paywall: agents pay per API call in USDC on-chain, with no accounts or API keys.
Has settlement been proven?
Honest answer: not yet on mainnet. The 402 challenge handshake is live and verifiable today; the funded-buyer on-chain settlement proof is in progress. A $1 USDC payment received 2026-09-22 was a manual send, not an x402 settlement.
Do I need an account or API key?
No. You need a wallet with USDC on Base and an x402 client. The challenge carries everything else.
What does each route cost?
Prices aren't public yet — request founding pricing and you'll get a written offer.
Why music-industry data?
Because CWI runs a real label: verified playlist placements, momentum data, rights snapshots and proof-of-use attestations — machine-readable, per call, with evidence attached.
Who is this for?
AI-agent builders, agent-commerce experimenters, and Base ecosystem devs who want to be first on a real x402 rail and help shape it.
